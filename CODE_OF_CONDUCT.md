# Code of Conduct

MultiAlt is a small community project. Everyone who opens an issue, sends a pull request or comments here is expected to keep it a friendly place.

## Expected

- Be respectful and patient, especially with people who are new to Roblox tools or to GitHub.
- Write in English, Português or Español — all three are welcome.
- Keep discussions about the project: bugs, ideas, code and documentation.

## Not accepted

- Insults, harassment, discrimination or personal attacks.
- Spam, advertising, scams or links to cheats, account stealers or "free Robux" sites.
- Posting someone else's private data — and never post cookies, passwords or `.ROBLOSECURITY` values, yours or anyone's.

## What happens

Comments, issues or pull requests that break these rules can be edited, hidden or deleted, and repeat offenders can be blocked from the repository. To report a problem with someone's behavior, open an issue or contact the maintainer through the GitHub profile [@luanmacea](https://github.com/luanmacea).
