    Made for people who play on more than one account

    Launching, joining, staying in the server and keeping accounts safe: the parts that used to take a dozen clicks per account now take one.

    Run them all at once

    Turn on Multi Roblox and open as many clients as your PC can handle. Select a group of accounts and Multi Launch sends them into the same game, one at a time with a safe delay, while the session panel shows each launch as it happens.

    • Launch queue you can cancel at any time
    • Arrange every Roblox window in a grid across the monitors you choose
    • Install Roblox builds side by side; finds Bloxstrap, Fishstrap and Voidstrap

    Land everyone in the same server

    The server finder scans the game’s servers and picks the one that suits your group. Best fit chooses the fullest server where everyone still fits, so nobody gets left in another lobby. Prefer it emptier, fuller, random or in a specific region? That’s one setting.

    • Paste any link: game, private server, share link, invite or deep link
    • See each account’s online friends and send the group to a friend’s server
    • Favorite games with several private server links each

    Stay in the game while you’re away

    Two ways to keep accounts from being kicked for idling. AFK mode taps a key or clicks in each window every few minutes, so nobody leaves the spot they’re in. Auto Rejoin closes and relaunches your alts on a timer, and never touches your main accounts.

    • The watcher closes a client that lost connection or ran low on memory
    • FPS cap, graphics, priority and FastFlags, with separate profiles for mains and alts
    • A live console explains every launch, rejoin and watcher action

    Your accounts stay yours

    Accounts are always encrypted on disk, with your password or with a key tied to this PC. Before a launch, isolation clears cache and registry traces so one account doesn’t inherit another’s session. Backups of accounts, settings, scripts and themes are one click away.

    • Add accounts by browser login, cookie, user:pass or the old RAM file
    • Live status: online, in game, in Studio, expired session or idle for 20+ days
    • Streamer mode hides usernames while you record

    Up and running in three steps

    Every file comes straight from the project’s GitHub releases.

    1. Download the installer

      The .msi is the one to pick. It installs for your Windows user only and updates itself when a new version comes out.

      Download .msiLatest release on GitHub

    2. Open it

      No administrator prompt. The app isn’t code-signed yet, so if Windows SmartScreen shows “Windows protected your PC”, choose More info and then Run anyway.

    3. Add your accounts

      Click Add and sign in through the browser, or paste a cookie. To run several clients at once, turn on Multi Roblox in Settings, General, with Roblox closed.

    Play it safe

    A tool that holds your accounts should be one you can check. Here’s what to know.

    Never make an rbx-player link because someone asked

    Anyone holding that link can join any game, or even Roblox Studio, as you. They can spend your Robux or get your account banned.

    Download only from GitHub

    Every button on this page points to the official GitHub releases. Copies posted anywhere else may be modified.

    The code is public

    Anyone can read it, audit it and build it themselves. Every release is scanned on VirusTotal and Windows Defender before it goes out.

    Questions

    Something not covered here? Open an issue on GitHub

    Why does my antivirus flag it?

    The app isn’t code-signed, and tools that launch game processes are a common false positive for antivirus models that learn from patterns. The .msi comes out clean on VirusTotal. If you’re unsure, read the code or build it yourself.

    How do I turn on Multi Roblox?

    Close Roblox, then go to Settings, General and turn on Multi Roblox.

    Why is Multi Roblox off by default?

    Roblox’s anti-cheat team has said running several clients may be seen as suspicious behavior. Turn it on at your own risk.

    Can I get banned for using it?

    The manager doesn’t break Roblox’s Terms of Service, but some games forbid alt accounts. Check the rules of the game you play.

    How do I back up my accounts?

    Settings, Misc, Data, Backups, Manage. The backup includes the device key, so if you don’t set a password in the app, anyone with the file can open your accounts. Set a password before keeping backups in the cloud.

    The window opened blank. What now?

    The app reopens itself without video acceleration after 25 seconds. You can force that by holding Shift while it opens. If it’s still blank, repair Microsoft Edge WebView2 Runtime in Windows Settings, Apps, restart and update your graphics driver.

    Does it work on Mac?

    Not yet. macOS support is partial and there’s no Mac download for now.

    Is it really free?

    Yes. No paid tier, no ads, no account to create. It’s licensed under GPL-3.0.
