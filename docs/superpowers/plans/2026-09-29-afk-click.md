# AFK mode por clique — plano de implementação

> **Para agentes:** SUB-SKILL OBRIGATÓRIA: superpowers:subagent-driven-development (recomendado) ou superpowers:executing-plans para executar tarefa por tarefa. Os passos usam checkbox (`- [ ]`).

**Objetivo:** o AFK mode ganha o modo **Clique** — clique esquerdo num ponto relativo (%) da janela de cada conta —, com ponto padrão, ponto próprio por conta e o "Marcar" que lê a posição do cursor.

**Arquitetura:** a lógica pura (porcentagem ↔ pixel, escolha do ponto, validação, resolução do Marcar) fica em `commands/afk.rs`, testável fora do Windows. O único código que injeta mouse é uma porta nova em `platform/windows/input.rs`, e a trava `afk_input_safety_tests` é dividida para permitir `INPUT_MOUSE`/`SetCursorPos` **só** ali. O ponto próprio de cada conta mora em `Account.Fields` e é resolvido pelo backend a cada ciclo.

**Stack:** Rust (Tauri 2, windows-sys), React 19 + TypeScript, vitest.

**Spec:** [docs/superpowers/specs/2026-09-29-afk-click-design.md](../specs/2026-09-29-afk-click-design.md)

## Restrições globais

- Porcentagem sempre travada em 0–100; valor não finito vira 50.
- O pixel calculado **nunca** sai da área interna da janela alvo (0% = primeira coluna/linha, 100% = última).
- Só clique **esquerdo** e simples. Clique só depois de `afk_window_is_ready` (foco confirmado) — igual à tecla.
- O cursor do usuário **volta** para onde estava depois do clique, inclusive quando o clique falha.
- O Marcar lê **só** a posição do cursor (`GetCursorPos`). Continuam proibidos no AFK mode: gancho, estado de tecla **e de botão**, entrada crua, `mouse_event`, `keybd_event`, `KEYEVENTF_UNICODE`.
- `INPUT_MOUSE`, `SetCursorPos` e `MOUSEEVENTF_` só podem aparecer em `platform/windows/input.rs`.
- Nenhuma janela é redimensionada.
- INI: `Afk.Mode` (`key` | `click`, default `key`), `Afk.ClickX` / `Afk.ClickY` (default `50`). Campos da conta: `AfkClickX` / `AfkClickY`.
- Códigos de erro vão para a tela, que traduz: `clickRefused` (ciclo) e `noCursor`, `noWindow`, `notAnAccountWindow`, `outsideGameArea` (Marcar).
- Textos novos em `src/locales/en` **e** `src/locales/pt`, mesma ordem de chaves.
- Commits em português, **sem** `Co-Authored-By` (CLAUDE.md). `bun run check` antes de cada commit.
- Suíte de iteração: `bun run t afk`.

```rust
/// Ponto do clique em porcentagem da área interna da janela (0–100 nos dois
/// eixos). Relativo de propósito: cai no mesmo lugar com a janela pequena,
/// grande ou maximizada, e nenhuma janela precisa ser redimensionada.
#[derive(Debug, Clone, Copy, PartialEq, serde::Serialize, serde::Deserialize)]
#[serde(rename_all = "camelCase")]
struct AfkPoint {
    x_pct: f64,
    y_pct: f64,
}

const AFK_DEFAULT_POINT: AfkPoint = AfkPoint { x_pct: 50.0, y_pct: 50.0 };

fn clamp_afk_percent(value: f64) -> f64 {
    if value.is_finite() { value.clamp(0.0, 100.0) } else { 50.0 }
}

impl AfkPoint {
    fn clamped(x: f64, y: f64) -> Self {
        Self { x_pct: clamp_afk_percent(x), y_pct: clamp_afk_percent(y) }
    }
}

/// Área interna (cliente) de uma janela, em coordenadas de tela.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
struct AfkClientRect {
    left: i32,
    top: i32,
    width: i32,
    height: i32,
}

/// Pixel de tela do ponto, **sempre dentro** da área interna: 0% é a primeira
/// coluna/linha e 100% a última, nunca a borda de fora.
fn afk_point_to_pixel(rect: AfkClientRect, point: AfkPoint) -> Option<(i32, i32)> {
    if rect.width <= 0 || rect.height <= 0 {
        return None;
    }
    let p = AfkPoint::clamped(point.x_pct, point.y_pct);
    let dx = ((p.x_pct / 100.0) * f64::from(rect.width - 1)).round() as i32;
    let dy = ((p.y_pct / 100.0) * f64::from(rect.height - 1)).round() as i32;
    Some((rect.left + dx, rect.top + dy))
}

/// O inverso, para o Marcar. `None` quando o cursor não está dentro da área
/// interna (em cima da borda, da barra de título ou fora da janela).
fn afk_pixel_to_point(rect: AfkClientRect, x: i32, y: i32) -> Option<AfkPoint> {
    if rect.width <= 0 || rect.height <= 0 {
        return None;
    }
    let (dx, dy) = (x - rect.left, y - rect.top);
    if dx < 0 || dy < 0 || dx >= rect.width || dy >= rect.height {
        return None;
    }
    let span_x = f64::from((rect.width - 1).max(1));
    let span_y = f64::from((rect.height - 1).max(1));
    // Duas casas: o bastante para a ida e volta cair no mesmo pixel em tela 4K.
    let round2 = |v: f64| (v * 100.0).round() / 100.0;
    Some(AfkPoint::clamped(
        round2(f64::from(dx) / span_x * 100.0),
        round2(f64::from(dy) / span_y * 100.0),
    ))
}

/// Ponto próprio da conta, dos campos `AfkClickX`/`AfkClickY`. Só vale com os
/// dois números: um sem o outro cai no padrão.
fn afk_point_from_fields(fields: &HashMap<String, String>) -> Option<AfkPoint> {
    let x = fields.get("AfkClickX")?.trim().parse::<f64>().ok()?;
    let y = fields.get("AfkClickY")?.trim().parse::<f64>().ok()?;
    if !x.is_finite() || !y.is_finite() {
        return None;
    }
    Some(AfkPoint::clamped(x, y))
}

/// O ponto de cada alvo: o próprio, se a conta tiver, senão o padrão.
fn afk_points_for_targets(
    targets: &[i64],
    default: AfkPoint,
    overrides: &HashMap<i64, AfkPoint>,
) -> HashMap<i64, AfkPoint> {
    targets
        .iter()
        .map(|uid| (*uid, overrides.get(uid).copied().unwrap_or(default)))
        .collect()
}
```

```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
enum AfkMode {
    /// Toca uma tecla da lista fechada.
    Key,
    /// Clique esquerdo num ponto relativo da janela da conta.
    Click,
}

impl AfkMode {
    /// Qualquer valor desconhecido vira `Key`: é o modo que já existia.
    fn parse(raw: &str) -> AfkMode {
        if raw.trim().eq_ignore_ascii_case("click") { AfkMode::Click } else { AfkMode::Key }
    }
    fn as_str(self) -> &'static str {
        match self { AfkMode::Key => "key", AfkMode::Click => "click" }
    }
}

/// O que o ciclo faz em cada conta. No clique o ponto já vem resolvido por
/// conta (o próprio ou o padrão), então o corpo bloqueante não lê store nenhum.
#[derive(Debug, Clone)]
enum AfkCycleAction {
    Key(String),
    Click(HashMap<i64, AfkPoint>),
}

fn validate_afk_start(mode: AfkMode, key: &str, user_ids: &[i64]) -> Result<(), String> {
    if mode == AfkMode::Key && afk_virtual_key(key).is_none() {
        return Err("Choose one of the AFK mode keys before starting".into());
    }
    if user_ids.is_empty() {
        return Err("Put at least one account in AFK mode before starting".into());
    }
    Ok(())
}
```

```rust
/// A ação do ciclo. O ponto próprio de cada conta é lido **agora**, dos campos
/// dela: mudar o ponto de uma conta vale no ciclo seguinte, sem religar o modo.
#[cfg(target_os = "windows")]
fn afk_cycle_action(app: &tauri::AppHandle, config: &AfkConfig, targets: &[i64]) -> AfkCycleAction {
    match config.mode {
        AfkMode::Key => AfkCycleAction::Key(config.key.clone()),
        AfkMode::Click => {
            let overrides: HashMap<i64, AfkPoint> = app
                .state::<AccountStore>() // o mesmo tipo que o lib.rs registra com .manage(...)
                .get_all()
                .unwrap_or_default()
                .into_iter()
                .filter(|a| targets.contains(&a.user_id))
                .filter_map(|a| afk_point_from_fields(&a.fields).map(|p| (a.user_id, p)))
                .collect();
            AfkCycleAction::Click(afk_points_for_targets(targets, config.default_point, &overrides))
        }
    }
}
```

```rust
                if body.contains(api) {
                    out.push((path.clone(), *api));
                }
            }
        }
        out
    }
```

```rust
/// Área interna da janela, em coordenadas de tela. `None` para janela nula,
/// fechada ou sem área.
pub fn client_rect_on_screen(hwnd: HWND) -> Option<crate::AfkClientRect> {
    if !window_exists(hwnd) {
        return None;
    }
    let mut rect = RECT { left: 0, top: 0, right: 0, bottom: 0 };
    if unsafe { GetClientRect(hwnd, &mut rect) } == 0 {
        return None;
    }
    let mut origin = POINT { x: 0, y: 0 };
    if unsafe { ClientToScreen(hwnd, &mut origin) } == 0 {
        return None;
    }
    let (width, height) = (rect.right - rect.left, rect.bottom - rect.top);
    if width <= 0 || height <= 0 {
        return None;
    }
    Some(crate::AfkClientRect { left: origin.x, top: origin.y, width, height })
}

/// Posição do cursor. **Só a posição**: nunca botão, nunca tecla.
pub fn cursor_position() -> Option<(i32, i32)> {
    let mut p = POINT { x: 0, y: 0 };
    if unsafe { GetCursorPos(&mut p) } == 0 { None } else { Some((p.x, p.y)) }
}

/// Botão esquerdo no lugar em que o cursor está. Privado: a única porta é
/// `click_afk_point`, que decide o lugar a partir da janela e da porcentagem.
fn send_mouse_button(down: bool) -> bool {
    let input = INPUT {
        r#type: INPUT_MOUSE,
        Anonymous: INPUT_0 {
            mi: MOUSEINPUT {
                dx: 0,
                dy: 0,
                mouseData: 0,
                dwFlags: if down { MOUSEEVENTF_LEFTDOWN } else { MOUSEEVENTF_LEFTUP },
                time: 0,
                dwExtraInfo: 0,
            },
        },
    };
    unsafe { SendInput(1, &input, std::mem::size_of::<INPUT>() as i32) == 1 }
}

/// Um clique esquerdo no ponto relativo `point` da janela `hwnd`, que o
/// chamador **já confirmou** estar em primeiro plano. O cursor do usuário volta
/// para onde estava, inclusive quando o clique falha.
pub fn click_afk_point(hwnd: HWND, point: crate::AfkPoint, hold_ms: u64) -> Result<(), String> {
    let rect = client_rect_on_screen(hwnd).ok_or("The window has no game area")?;
    let (x, y) = crate::afk_point_to_pixel(rect, point).ok_or("The window has no game area")?;
    let back = cursor_position();

    let result = (|| {
        if unsafe { SetCursorPos(x, y) } == 0 {
            return Err("Windows did not move the cursor".to_string());
        }
        std::thread::sleep(std::time::Duration::from_millis(15));
        if !send_mouse_button(true) {
            return Err("Windows refused the synthetic click".to_string());
        }
        std::thread::sleep(std::time::Duration::from_millis(hold_ms));
        // Botão que fica pressionado vira arrastar dentro do jogo.
        for _ in 0..KEY_UP_ATTEMPTS {
            if send_mouse_button(false) {
                return Ok(());
            }
            std::thread::sleep(std::time::Duration::from_millis(KEY_UP_RETRY_MS));
        }
        Err("Windows did not release the synthetic click".to_string())
    })();

    if let Some((bx, by)) = back {
        unsafe { SetCursorPos(bx, by) };
    }
    result
}
```

```ts
/**
 * Ponto do clique do AFK mode: porcentagem da área interna da janela (0-100).
 * O ponto próprio de uma conta mora em `Account.Fields` (`AfkClickX`/`AfkClickY`);
 * o backend lê os mesmos campos a cada ciclo (`afk_point_from_fields`).
 */
export type AfkMode = "key" | "click";
export interface AfkPoint {
  x: number;
  y: number;
}

export const AFK_DEFAULT_POINT: AfkPoint = { x: 50, y: 50 };
const FIELD_X = "AfkClickX";
const FIELD_Y = "AfkClickY";

export function clampAfkPercent(value: number): number {
  return Number.isFinite(value) ? Math.min(100, Math.max(0, value)) : 50;
}

export function readAfkPoint(fields: Record<string, string> | undefined): AfkPoint | null {
  const x = Number.parseFloat(fields?.[FIELD_X] ?? "");
  const y = Number.parseFloat(fields?.[FIELD_Y] ?? "");
  if (!Number.isFinite(x) || !Number.isFinite(y)) return null;
  return { x: clampAfkPercent(x), y: clampAfkPercent(y) };
}

export function writeAfkPoint(
  fields: Record<string, string> | undefined,
  point: AfkPoint | null
): Record<string, string> {
  const next = { ...(fields ?? {}) };
  delete next[FIELD_X];
  delete next[FIELD_Y];
  if (point) {
    next[FIELD_X] = String(clampAfkPercent(point.x));
    next[FIELD_Y] = String(clampAfkPercent(point.y));
  }
  return next;
}

export function formatAfkPoint(point: AfkPoint): string {
  return `${clampAfkPercent(point.x)}% × ${clampAfkPercent(point.y)}%`;
}
```
